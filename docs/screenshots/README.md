# Prints do projeto

As capturas desta pasta aparecem no [README principal](../../README.md).

| Arquivo | Conteúdo |
| --- | --- |
| `catalogo.png` | Visão geral da biblioteca |
| `pastas.png` | Navegação por pastas |

| `preparacao-mp4.png` | Preparação para TV |

Para atualizar uma captura, substitua o arquivo correspondente. Para adicionar outra, use PNG, JPEG ou WebP e um nome sem espaços, incluindo o caminho relativo no README principal:

```markdown
![Catálogo do Cinema Local](docs/screenshots/catalogo.png)
```

Use caminhos relativos ao repositório para que as imagens apareçam também no GitHub.
