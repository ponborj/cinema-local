# Prints do projeto

Adicione aqui os screenshots que deseja mostrar no repositório. Use PNG, JPEG ou WebP e nomes sem espaços.

| Arquivo sugerido | Conteúdo |
| --- | --- |
| `catalogo.webp` | Visão geral da biblioteca |
| `pastas.webp` | Navegação de uma coleção ou série |
| `player.webp` | Player com áudio e legendas |
| `preparacao-mp4.webp` | Progresso da preparação para TV |
| `mobile.webp` | Layout em tela pequena |
| `tv.webp` | Interface no navegador da TV |

Quando adicionar uma imagem, inclua o caminho relativo no README principal, por exemplo:

```markdown
![Catálogo do Cinema Local](docs/screenshots/catalogo.webp)
```

Use caminhos relativos ao repositório para que as imagens apareçam também no GitHub.
